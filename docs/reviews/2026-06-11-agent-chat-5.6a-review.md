## API contracts (frozen for 5.6b)

### `POST /api/agent-threads`

```json
{ "title?": "string", "initialMessage?": "string" }
→ { "ok": true, "threadId", "messageId?", "wakeupId?", "coalesced" }
```

- Super Agent added as `coordinator` participant.
- Creator added as `human` participant.
- `initialMessage` triggers `chat` wakeup with `{ threadId, triggerMessageId }`.

### `GET /api/agent-threads?status=open|done|all&cursor=&limit=`

- `open` = statuses `open|routing|active|awaiting_human|stalled`.
- Paginated by `(updatedAt desc, id desc)`.

### `GET /api/agent-threads/[id]`

- Returns thread, participants (with agent/user display), messages asc.

### `POST /api/agent-threads/[id]/messages`

```json
{ "content": "string", "targetAgentId?": "string" }
→ { "ok": true, "messageId", "wakeupId", "coalesced" }
```

- Idempotency key: `chat:{threadId}:{messageId}`.
- `targetAgentId` stored but Super-only routing in 5.6a (always wakes Super).
